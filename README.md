## 🚀 Featured Projects

### 🔐 [Sentinel AI — Zero Trust AI Firewall](https://github.com/S-Rais)
> *Python · FastAPI · Multi-Agent Systems · ML · LLM*

A multi-layer zero-trust proxy firewall for agentic AI systems. Intercepts prompt injection, memory extraction, and tool-abuse attacks using a hybrid detection engine (rule-based + ML + semantic similarity). Achieved **93% detection rate with 0.91 precision** across adversarial test suites. Research paper submitted for publication.

---

### 🛡️ [Network Intrusion Detection System (NIDS)](https://github.com/S-Rais)
> *Python · Scikit-learn · DBSCAN · Random Forest · PCA*

Two-stage detection pipeline on NSL-KDD: unsupervised DBSCAN clustering for anomaly segmentation + supervised Random Forest classification. Achieved **94%+ accuracy**. Applied PCA-based dimensionality reduction cutting inference latency by **40%** with no accuracy loss.

---

### 💼 [Personal Financial ERP Platform](https://github.com/S-Rais/INVENTORY.github.io)
> *React.js · Node.js · Express.js · MongoDB · Python · REST API · MySQL*

Full-stack ERP web app for real-time inventory management. ML recommendation engine forecasts stock requirements with **~85% accuracy**. JWT-secured RESTful APIs, MongoDB aggregation pipelines, and a Chart.js CRUD dashboard.

---

### 🌾 [AI Chatbot for Kerala Farmers](https://github.com/S-Rais/Ai-for-kerala-farmers)
> *Python · Flask · NLTK · scipy · JavaScript · Web Speech API*

Bilingual (English-Malayalam) NLP chatbot with voice I/O for **500+ rural farmers** with low digital literacy. Multi-turn contextual conversation history improved user satisfaction scores by **30%** in usability testing.
